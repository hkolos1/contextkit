Toolpeek is an open-source Chrome extension that shows the WebMCP tools a website exposes to AI agents, and lets you inspect, run and audit them from the side panel.

Everything a page hands to an agent, in one panel.

WebMCP lets websites register typed tools that AI agents call instead of clicking through the page. Toolpeek makes those tools visible and testable.

Local by default. No account, backend, analytics or host permissions. Access is granted per tab when you click the toolbar icon. The only network requests go to the AI provider you configure in the Agent tab, with your own key.

Install

Toolpeek runs in desktop Chrome 116 or later. Live discovery needs a page that registers WebMCP tools and a Chrome build with WebMCP: for local testing, enable chrome://flags/#enable-webmcp-testing and relaunch Chrome.
