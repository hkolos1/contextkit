ContextKit v0.2.0 adds an optional Agent tab: describe a task in plain language and let a model drive the page's WebMCP tools.

- Choose Gemini (default), ChatGPT or Claude and add that provider's API key in the Agent settings. A Gemini key from Google AI Studio works on its free tier.
- Read-only tool calls run directly. Other calls wait for your approval in the side panel, and consequential or destructive ones always do.
- Agent tool calls use the same guarded execution path as the Playground, appear in Activity, and may wait up to five minutes for actions the user completes in the page.
- Keys stay in this browser's extension storage and are sent only to their provider. Without a key, ContextKit makes no network requests, as before.

Download **contextkit-v0.2.0.zip** below, extract it, and select the extracted folder with **Load unpacked** in Chrome Developer mode (or reload the extension if you installed v0.1.0). For live local testing, enable `chrome://flags/#enable-webmcp-testing` and relaunch Chrome.
