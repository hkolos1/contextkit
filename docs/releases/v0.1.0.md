ContextKit’s first public release brings WebMCP inspection and manual testing to the Chrome side panel.

- Browse registered tools and their schemas, safety annotations and origins.
- Validate arguments, explicitly run tools and inspect results, timings and errors.
- Audit live or imported inventories, review local activity and export JSON or standalone HTML reports.

Download **contextkit-v0.1.0.zip** below, extract it, and select the extracted folder with **Load unpacked** in Chrome Developer mode. For live local testing, enable `chrome://flags/#enable-webmcp-testing` and relaunch Chrome. Native workflows were verified on Chrome for Testing 158.0.8127.88 and 159.0.8154.6.
