Toolpeek v1.0.0 is the first release under the new name. **ContextKit is now Toolpeek**: same extension, new identity, a redesigned interface and a home at https://toolpeek.web.app.

**Rebrand**
- New name, `{•}` logo and aurora design system (deep night surfaces, teal, green-cyan-blue accents).
- Settings, history and saved API keys carry over when you replace the files of an existing unpacked install and click Reload.

**Redesigned extension**
- New dark and light themes with Geist typography. System stays the default and follows your OS; pick it from a segmented control in Settings.
- Tool details summarize parameters (type, required, description) with the raw JSON one click away.
- Responses show a success or error badge and duration, with a one-click copy.
- `/` focuses tool search and Ctrl/⌘+Enter runs the selected tool.
- Clearer guidance when a page exposes no WebMCP tools, a show/hide toggle for API keys, copy confirmations that dismiss themselves, and enum options shown without JSON quotes.

**Demo store**
- The bundled demo is now a small shop with a cart: `add_to_cart` and `checkout` join the inventory tools, so you can try a full purchase from the Playground.

**Project**
- Landing page and privacy policy at https://toolpeek.web.app. The site registers its own read-only WebMCP tools, so you can try Toolpeek on it.
- Rewritten README, privacy policy, branding guidelines and Chrome Web Store submission notes.
- Chrome Web Store readiness: listing copy, permission justifications, privacy disclosures and store images are prepared. The extension is not yet on the Chrome Web Store.

**Install**: download **toolpeek-v1.0.0.zip** below, extract it, and select the folder with **Load unpacked** at `chrome://extensions` (Developer mode). Upgrading from ContextKit: replace the contents of your existing folder and click **Reload**. For live local testing, enable `chrome://flags/#enable-webmcp-testing` and relaunch Chrome.
